# WhiteDNS 1.6.9 — Interface and permission fixes

- Adopt WhiteVPN’s colors, Vazirmatn fonts, connection control and compact component styling throughout the app.
- Improve Persian alignment, text scaling, keyboard clearance, navigation and home profile panels.
- Hide completed setup guidance and keep notification permission cancellation retryable across recreation and VPN/Proxy mode changes.
- Make traffic values, warnings, profile actions and settings more compact while retaining accessible touch targets.
- Fix a startup initialization crash during automatic subscription refresh.
- Refresh packaged StormDNS and CottenDNS clients from the existing pinned source commits; retain the source-built SOAR client.

Existing profiles, account subscriptions and saved preferences remain supported.
The official signed build can update the installed app without clearing data.
